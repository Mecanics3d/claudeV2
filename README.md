Utilisation sur Android

Activez le Bluetooth du téléphone. 
Sur Android 11 et versions antérieures, activez aussi la localisation ;
sur Android 12 et suivants, 
autorisez l’accès aux « appareils à proximité » si Chrome le demande.
Ouvrez l’adresse GitHub Pages de votre page dans Chrome (Samsung Internet et Edge fonctionnent aussi ; Firefox ne gère pas le Bluetooth web).
Touchez Connecter le micro:bit, 
puis choisissez « BBC micro:bit [xxxxx] » dans la liste.

N’appairez pas la carte dans les réglages Bluetooth d’Android : la connexion se fait uniquement depuis la page.
Si la carte y apparaît déjà de test précédents, choisissez « Oublier » ou « Dissocier »
